# Great Minds AI — Retention decisions required before launch

No retention durations are set by this document. Do not automatically purge records until the product owner obtains appropriate legal/privacy review for each launch territory.

| Data category | Proposed handling pending approval |
|---|---|
| Auth account | Delete only after verified request, dependency review and secure server-side processing |
| Guardian relationship and consent evidence | Preserve only as long as legally necessary; define evidence and expiry rules with counsel |
| Student learning progress | Parent/guardian-led request review; decide export, deletion and any legally required retention |
| Homework and submissions | Resolve teacher/classroom ownership and student rights before deletion |
| Classroom membership and classroom records | Transfer or formally close classroom before teacher account deletion |
| Security/rate-limit logs | Define short, justified retention and access restrictions |
| Backups and third-party processors | Document backup expiry and downstream deletion process |

Required approval fields: territory, category, retention duration, legal basis, deletion trigger, backup expiry, responsible role, and review date.
